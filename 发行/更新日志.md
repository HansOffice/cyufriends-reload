CyuFriends-Reload 更新日志

[1.1.8] - 2026-10-07

外部物品支持适配最新版 CraftEngine 26.x 物品构建与多层解包

[1.1.7] - 2026-10-06

修复在 1.21 部分 Paper 与 Folia 服务端环境下可能加载异常的问题

[1.1.6] - 2026-10-05

支持切换中英文语言
支持 Paper、Folia 与 Legacy 三端运行包
帮助指令支持按专题分类查看，支持聊天框点击填词与分页浏览
菜单动作支持 open 界面跳转、refresh 原位刷新、actionbar 提示与 title 标题
跨服通信支持将 max-clock-skew-seconds 设为 0 关闭时间误差校验，并在超限时输出具体偏差毫秒
本地 SQLite 数据库文件统一归入 data 目录，旧版数据库文件自动迁移
修复菜单内物品名称与描述文本默认显示为斜体的问题

[1.1.5] - 2026-08-23

优化富文本消息渲染，修复高版本下文本序列化异常

[1.1.3] - 2026-07-19

CyuID UID 写入完成后统一发布变更事件，好友与代理同步自动响应
跨服代理启用时自动校验共享 MySQL 存储，阻止本地 SQLite 分裂身份数据
修复好友资料菜单头像异步刷新后传送按钮不执行的问题，重绘后保留菜单动作

[1.1.2] - 2026-05-10

修复 /friend reload 未完整刷新进服摘要、语言、声音和 GUI 的问题
拒绝将 Citizens NPC 添加为好友，并补齐黑名单公共聊天过滤的管理员绕过权限
私聊统一收归 /friend msg、/friend reply 和 /friend messages，不再占用服务器系统私聊指令
调整好友菜单为低饱和深灰与玻璃边框展示

[1.0.8] - 2026-04-15

SkinsRestorer 头像改为异步预热，菜单首次打开先显示可用缓存或默认头像，解析完成后自动刷新当前菜单

[1.0.7] - 2026-03-20

分页禁用态按钮支持自定义材质、CustomModelData 与外部材质插件
优化 CraftEngine 菜单图标桥接，复用方法缓存减少渲染开销

[1.0] - 2026-01-01

提供好友关系流转、分组标签、好友传送、点对点私聊、离线留言中心、动态广场、主页留言墙、个人名片与生日祝福
支持数据驱动 GUI，可通过 gui 目录定制菜单布局与点击动作
提供 PlaceholderAPI 变量支持与附属插件开发 API
