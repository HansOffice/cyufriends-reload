CyuFriends-Reload 使用文档

CyuFriends-Reload 是面向现代 Minecraft 服务器的高性能好友与轻社交系统，提供好友申请、关系管理、分组标签、好友传送、好友私聊、离线留言中心、动态广场、留言墙主页、个人资料、生日提醒以及社交通知

插件既可以作为单一子服的完整玩家社交底座，也可以接入配套跨服代理端（支持 Velocity 与 BungeeCord），在多服架构下无缝共享好友在线状态、跨服私聊与跨服传送

版本 1.1.8 好友关系与传送 分组与自选标签 私聊与离线留言 动态圈与留言墙 交流群 331910315

版本与选用

放入插件

按服务端类型选择对应 jar 放进服务器的 plugins 文件夹

启动一次

启动服务器生成默认配置文件，控制台确认插件加载成功

设置权限

普通玩家至少需要 cyufriends.use，管理与配置权限按需授予管理员

进服测试

进入游戏执行 /friend 测试功能，确认界面交互与配置正常

选择哪个 jar

文件 适合场景
cyufriends-reload-paper-1.1.8.jar 1.21 起的 Paper / Purpur 服务端
cyufriends-reload-folia-1.1.8.jar 1.21 起的 Folia 服务端
cyufriends-reload-legacy-1.1.8.jar 1.16.5 至 1.20.x 的 Spigot / Paper 服务端
三个 jar 只放一个；当前文档对应 1.1.8；功能完全一致，根据服务端环境选择对应 jar 即可

核心生成文件速查

文件 / 路径 主要功能 常用修改项目
config.yml 主配置文件 数据库连接、各模块开关、默认好友上限、跨服参数、Debug 开关
lang/*.yml 多语言提示与反馈文案 提示与交互文本（zh_cn / en_us），支持在 config.yml 中一键切换
sounds.yml 交互音效配置 好友申请、接收私聊、操作成功与失败时的音效反馈
gui/*.yml GUI 菜单配置 好友列表、申请列表、个人资料、动态广场等界面的布局与图标
Permissions.yml 权限节点速查表 普通玩家功能、VIP 扩容档位与管理员节点参考
Placeholder.yml PAPI 变量参考清单 计分板、聊天格式与外部菜单可引用的变量字典

跨服代理网桥

当服务器采用群组跨服架构时，需在代理端（Velocity 或 BungeeCord）安装配套代理插件，并在各子服 config.yml 中启用 proxy 模块

代理端文件与部署

Velocity 代理端放置 cyufriends-reload-proxy-velocity-1.0.3.jar

BungeeCord 代理端放置 cyufriends-reload-proxy-bungee-1.0.3.jar

后端子服部署

每个 Paper/Purpur 子服放置 cyufriends-reload-paper-1.1.8.jar

每个 Folia 子服放置 cyufriends-reload-folia-1.1.8.jar

每个 1.16.5 至 1.20 子服放置 cyufriends-reload-legacy-1.1.8.jar

代理端配置示例 (proxy.yml)

proxy:
  server-id: "proxy"
  channel: "cyufriends:gateway"
  protocol-version: 1

security:
  secret: "change-this-secret"
  # 允许的消息时间误差 (秒)，填 0 或负数可关闭时间误差校验
  max-clock-skew-seconds: 15
  deduplication-ttl-seconds: 60

transport:
  request-timeout-seconds: 15
  execute-timeout-seconds: 20

logging:
  debug: false

子服配置示例 (config.yml)

modules:
  proxy: true

proxy:
  enabled: true
  server-id: "survival-1"            # 对应代理端中本子服的注册名称
  channel: "cyufriends:gateway"      # 跨服通信频道名
  protocol-version: 1                # 协议版本，所有端必须一致
  secret: "change-this-secret"       # 共享密钥，所有端必须一致
  max-clock-skew-seconds: 15         # 允许的消息时间误差（秒），填 0 或负数可关闭时间误差校验
  direct-message-timeout-seconds: 8  # 跨服私聊回执超时（秒）
  teleport-precheck-timeout-seconds: 6 # 跨服传送预检超时（秒）
  presence-refresh-seconds: 60       # 在线状态低频刷新
时钟漂移与排障说明
在 Windows 宿主机搭配 WSL2、Docker 或虚拟机等混合组网环境下，各系统之间的系统时钟经常存在超过 15 秒的偏差；若控制台出现时钟偏差告警，可校准各机器时间，或者将 max-clock-skew-seconds 设置为 0 彻底关闭时钟校验，此时插件会自动使用 120 秒安全去重窗口保障跨服消息不被重复消费

核心交互动线

插件整体以极简直观的 GUI 为核心入口，同时为习惯指令的高级玩家保留了纯粹的命令体系

发送好友申请

玩家通过 /friend add <玩家> 或在 GUI 搜索、在线玩家列表点击头像发出申请，可附带简短留言

处理好友申请

被申请方通过 /friend requests 或点击聊天栏交互按钮，即可快速同意或拒绝好友申请

关系互动与传送

成为好友后，双方可发起好友传送、互相私聊、查看个人主页、设置个性化备注、标签与专属分组

社区社交广场

玩家通过 /status 分享服务器日常动态，通过 /wall 给好友主页留言，互赞互动沉淀社区关系

模块架构

所有功能采用高内聚的模块化开关设计，服主可根据自己服务器的玩法偏好按需启闭：

modules:
  proxy: false    # 跨服通信模块（单服模式请保持 false）
  friend: true    # 好友核心模块（必须开启，关闭后社交相关子功能随之停用）
  group: true     # 好友分组模块
  chat: true      # 好友私聊与留言模块
  social: true    # 动态圈与留言墙模块
  profile: true   # 个人资料与主页模块
模块名称 核心职责 关闭影响
friend 好友关系、申请流转、黑名单、好友传送与好友列表 GUI 好友功能完全隐藏，其他社交子模块自动降级停止
group 自定义分组、分组成员管理、批量移动好友 好友菜单不显示分组列表，好友仅保留平铺展示
chat 好友私聊、快速回复、离线留言中心 隐藏 /friend msg 指令与未读消息箱
social 动态圈发布、动态点赞评论、留言墙与留言审核机制 隐藏 /status 与 /wall 入口
profile 玩家个人主页、个性签名、生日提醒与社交通知设置 隐藏个人主页展示与生日祝福广播
proxy Velocity / Bungee 跨服消息路由与在线状态同步 仅在当前单服内部结算数据，不广播跨服数据包

好友与传送

好友关系包含完整的申请、审批、拉黑、删除与传送协同流程：

好友申请与冷却

支持玩家名或 UID 查找；自动阻断向 Citizens NPC 发送申请

服主可在 requestLimits 配置每日最大申请次数与两次申请间的冷却时间

好友传送与世界管控

支持直接传送、确认后传送与拒绝传送三种个人偏好模式

服主可在 disabledWorlds 列表中填入副本世界、PVP 竞技场等禁用传送区域

好友传送常用配置

settings:
  tp-request-timeout-seconds: 60  # 传送确认请求保留时间 (秒)
disabledWorlds:
  - "pvp_arena"
  - "dungeon_world"

分组与标签

分组适合做“公会伙伴 / 现实朋友 / 组队队友”等长期大类划分；标签适合做“建筑师 / 红石专家 / 锻造师”等灵活标记：

能力项 主要入口 应用说明
分组管理 /friend group 创建、重命名、删除自定义分组，查看组内好友
批量移动 /friend groupmoveall 将指定组内的所有成员一键批量归并到目标分组
分组规则 /friend grouprules 针对特定分组单独配置专属传送权限、上线通知与广播策略
好友标签 /friend tag <玩家> <标签> 为好友添加灵活短文本标签，便于分类查找
主标签与颜色 /friend tagcolor 在 GUI 中为标签定制专属展示颜色并在聊天栏中高亮
标签筛选 /friend tagfilter 在好友菜单中按标签快速筛选目标玩家

私聊与留言

私聊通道仅在已确立好友关系的玩家之间开放，既保证社交私密性，又避免公共骚扰：

独立指令空间

使用 /friend msg 与 /friend reply，绝不占用服务器原有基础指令 /msg 或 /tell

离线留言中心

目标好友离线时自动存为离线留言，好友上线后通过通知中心或 /friend messages 查阅

黑名单聊天过滤

被拉黑玩家的公屏消息会被自动静默过滤，管理员拥有专属绕过权限节点

私聊参数配置

messageCooldown: 60               # 私聊发送冷却时间 (秒)
messageExpiration: 604800         # 离线留言保留时长 (秒，0 为永久保存)
chatFilter:
  hide-blocked-public-chat: true  # 自动隐藏黑名单玩家的公屏消息
  bypass-permission: "cyufriends.bypass.chatfilter"

动态与留言墙

动态类似于服内玩家的朋友圈，留言墙则是挂在玩家个人主页上的寄语板，两者均支持互动与审核：

系统 主要能力 管理与控制
动态广场 (Status) 发布动态短文、公开范围设置（公开/仅好友/私密）、评论、点赞与置顶 支持配置最大保留动态条数、发布冷却与评论冷却
主页留言墙 (Wall) 给目标玩家主页发布留言、留言回复、点赞、置顶与个人清理 可配置发布/回复冷却，支持开启留言审核机制（墙主先审后放行）
关系时间线 自动记录私聊往来、动态互动与留言互动 在好友资料页直观查看与该好友的历史互动足迹

资料与生日

玩家可个性化打理自己的社交名片，向全服展示自己的个性签名与生日信息：

个人签名

通过 /bio <文本> 设置个性简介，配置可限定签名最大长度与列表预览字数

生日提醒与祝福

通过 /birthday <yyyy-MM-dd> 绑定生日，可配置允许修改次数与定时全服生日广播

生日与签名参数

birthdayReminder:
  enabled: true
  checkTime: "00:05"              # 每日检查并广播的时间
  advance-days: [0, 1]            # 当天及提前 1 天发出提醒
profile:
  bio-max-length: 64              # 签名最大字数
  bio-preview-length: 32          # 列表预览字数

存储与基础设置

数据层支持 SQLite 与 MySQL 两种存储引擎：

database:
  type: SQLite                    # 单服推荐 SQLite，跨服环境必须统一配置为 MySQL
  host: localhost
  port: 3306
  database: cyufriends
  username: root
  password: ""

settings:
  request-cooldown: 60            # 好友申请默认冷却 (秒)
  text-input-timeout-seconds: 90  # 聊天栏输入模式等待超时 (秒)
  tp-request-timeout-seconds: 60  # 传送确认超时 (秒)
  max-friends-default: 50         # 默认最大好友数量
SQLite 数据库文件统一平滑收纳在插件目录下的 data/data.db 中，启动时若发现旧版根目录数据会自动完成无损迁移

权限档位阶梯

服主可通过权限节点为 VIP、赞助者或管理团队配置进阶的社交特权与限额：

权限档位类型 配置路径示例 对应权限节点 控制项
好友申请配额 requestLimits.vip cyufriends.request.vip 每日申请次数限制、申请冷却间隔
动态圈配额 statusLimits.vip cyufriends.status.vip 最大保留动态数、发动态冷却、评论冷却
留言墙配额 wallLimits.vip cyufriends.wall.vip 最大保留留言数、发留言冷却、回复冷却
生日修改权限 birthdayLimits.vip cyufriends.birthday.vip 一年内允许重新修改生日的次数上限

命令与权限

指令 所需权限 详细说明
/friend cyufriends.use 好友系统主界面入口（简写别名：/cf、/cfs、/cyuf）
/friend add <玩家> cyufriends.use 向目标玩家发起好友申请
/friend msg <好友> <内容> cyufriends.command.msg 向好友发送私聊消息（离线则存为未读留言）
/friend reply <内容> cyufriends.command.reply 快速回复最近一位与自己私聊的好友
/friend messages cyufriends.command.messages 打开未读离线留言消息中心
/status cyufriends.command.status 打开动态广场面板，发布或查阅全服动态
/wall cyufriends.command.wall 打开个人留言墙或给其他玩家留言
/bio <内容> cyufriends.command.bio 修改个人主页签名
/birthday <日期> cyufriends.command.birthday 绑定或查看个人生日
/settings cyufriends.command.settings 打开个人社交隐私与通知偏好设置

管理员运维

管理员功能集成了诊断、缓存刷新、模块状态检查与安全重载，均要求 cyufriends.admin 权限：

管理命令 用途说明
/friend reload 安全重载配置、语言、音效和 GUI 菜单；若配置出错会自动回滚保留旧运行时
/friend admin inspect <玩家> 全景透视玩家 UID、在线节点、好友总数、黑名单、待审留言及最近互动记录
/friend admin rebuild <玩家> 即时清空并重建指定玩家的数据缓存（在线立即重载，离线下次上线触发）
/friend admin cache 打印当前好友、申请、黑名单、私聊等各类内存缓存对象总数
/friend admin health 全项健康度体检：校验数据库连通、PAPI 挂载、代理通道及运行健康度
/friend admin proxy 查看跨服代理网桥的实时连接状态、收发包指标与在线节点目录
/friend admin moderation 查看全服待审核留言看板，支持一键批准或驳回违规内容

PlaceholderAPI

插件原生注册 cyufriends 变量前缀，并向前兼容旧版 friends 前缀：

占位符变量 数据含义与返回值
%cyufriends_total_count% 当前玩家拥有的好友总数
%cyufriends_request_count% 当前玩家收到的待处理申请总数
%cyufriends_offline_messages_count% 当前玩家未读的离线留言条数
%cyufriends_daily_requests_remaining% 当前玩家今日剩余可发送的申请额度
%cyufriends_note_<player>% 当前玩家为指定好友设置的备注名
%cyufriends_group_<player>% 指定好友所在的自定义分组名
%cyufriends_is_friend_<player>% 判断指定玩家是否为好友（返回 是 / 否）
%cyufriends_birthday_<player>% 指定玩家的生日日期文本
%rel_cyufriends_is_friend% 双向关系变量：判断当前双方是否为好友
%rel_cyufriends_is_friend_bool% 双向关系变量：布尔值返回（true / false）

菜单与自定义图标

所有界面均存放于 gui/ 目录，纯数据驱动配置，无需编写代码即可深度定制：

外部物品桥接

按钮材质全面兼容原版及 ItemsAdder (ia:item)、Oraxen (ox:item)、Nexo (nexo:item) 与 CraftEngine (ce:item)

资源包模型 (CMD)

可直接指定 custom_model_data: 10001，或直接采用紧凑语法 material: PAPER#10001

异步皮肤与防抖

玩家头像支持本地缓存与 SkinsRestorer 异步加载，所有菜单按钮内建防抖保护，避免玩家手滑连点

若需开启空手 Shift + 右键玩家呼出快捷交互菜单，可在 config.yml 中配置 interactionSettings.shiftRightClickMenu: true

菜单动作语法速查

动作指令 执行效果与语法示例
[open] <界面名> [参数] 原生打开指定子界面，如 [open] friends_list 或 [open] friend_profile %target_name%
[refresh] 原位静默刷新当前界面数据，不闪烁界面
[close] 关闭当前打开的界面
[actionbar] <内容> 向玩家物品栏上方发送 ActionBar 快捷提示，支持 MiniMessage 颜色渐变
[title] <主标题>[;<副标题>] 向玩家屏幕正中央发送大屏标题通知
[message] <文本> 向玩家聊天栏直接发送单条消息
[sound] <音效> [音量] [音调] 播放指定原版音效或 sounds.yml 预设别名，如 [sound] UI_BUTTON_CLICK 1.0 1.2
[player] <指令> 以玩家自身身份执行指定指令（不带斜杠）
[console] <指令> 以控制台身份执行指令，支持 %player% 变量

配置建议

  1. 用默认配置启动一次，生成好友配置、语言、音效与交互面板
  2. 给默认玩家组 cyufriends.use，给管理员 cyufriends.admin
  3. 在 config.yml 中配置跨服模式（单服 SQLite / 跨服 MySQL）与同步密钥
  4. 按服务器规则调整好友上限、传送冷却与留言审核等参数
  5. 根据服务器主题微调 gui/friends_list.yml 好友列表与申请界面
  6. 使用两个测试账号执行 /friend add 测试发送与接受好友申请
  7. 测试好友私聊、状态通知与跨服传送等基础功能
  8. 确认数据同步与并发操作安全无异常后，正式向全服玩家开放
